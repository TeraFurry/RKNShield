# RKNShield 🛡️

**RKNShield** — консольная утилита для Windows, предназначенная для контроля корневых сертификатов безопасности и управления блокировкой нежелательного программного обеспечения (российских браузеров и сервисов).

---

## 📌 Что умеет программа

1. **Интеллектуальный поиск сертификатов:** Сканирует системные хранилища сертификатов Windows по содержимому (отпечатки SHA-1, данные владельца и издателя), а не только по названию.
2. **Блокировка сертификатов Минцифры:** Удаляет найденные корневые сертификаты и принудительно добавляет их в системный чёрный список Windows (`Disallowed`).
3. **Блокировка браузеров:** Предотвращает запуск российских браузеров (Яндекс.Браузер, Atom, Спутник, Амиго, Комета) с помощью механизма `Image File Execution Options` (IFEO) в реестре.
4. **Режим «Сторож»:** Создает защищенную фоновую задачу в планировщике Windows, которая каждые 30 минут проверяет систему и автоматически устраняет попытки восстановления удаленных сертификатов или разблокировки приложений.
5. **Безопасный бэкап и откат:** Сохраняет копии удаленных сертификатов и позволяет в любой момент полностью вернуть систему в исходное состояние через встроенное меню.

## 📥 Скачать и запустить (для пользователей)

Вам **не нужно** устанавливать Python или собирать программу самостоятельно — готовый файл уже собран.

1. Перейдите на страницу релиза: **[готовый файл v1.0.0](https://github.com/TeraFurry/RKNShield/releases/tag/v1.0.0)**
2. В блоке **Assets** скачайте файл **`default.exe`**.
3. Запустите `default.exe` **от имени администратора** (правой кнопкой мыши -> *Запуск от имени администратора*).

---

## 🛠️ Для разработчиков (сборка из исходников)

Если вы хотите внести изменения в код и собрать программу самостоятельно:

1. Убедитесь, что у вас установлен Python.
2. Запустите скрипт сборки `build_exe.bat`.
3. Готовый файл появится по пути: `dist\RKNShield.exe`.
